# VGG-CIFAR10-Research

Research-style implementation and experimental comparison of **VGG-11, VGG-13 and VGG-16** CNN architectures on CIFAR-10, with and without Batch Normalization.

## Research objective
- Effect of increasing CNN depth from VGG-11 → VGG-13 → VGG-16
- Effect of Batch Normalization (BN)
- Parameter growth and training cost
- Accuracy, loss and convergence behavior
- Confusion matrices and per-class performance
- Why stacked 3×3 convolutions are useful compared with a single larger convolution

## Experiments
| Architecture | Batch Normalization |
|---|---|
| VGG-11 | No |
| VGG-11 | Yes |
| VGG-13 | No |
| VGG-13 | Yes |
| VGG-16 | No |
| VGG-16 | Yes |

The same CIFAR-10 train/validation split, augmentation pipeline, optimizer family and evaluation procedure are used to make the comparison meaningful.

## Dataset
**CIFAR-10** contains 60,000 RGB images of size 32×32 belonging to 10 classes.

Classes: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck.

## Implementation
- CIFAR-10 loading and preprocessing
- Fixed train/validation split
- CIFAR-10 augmentation
- Configurable VGG architecture builder
- Optional Batch Normalization
- SGD with momentum and cosine learning-rate scheduling
- Mixed precision on CUDA
- Model parameter counting
- Training and validation curves
- Test-set evaluation
- Confusion matrices and per-class accuracy
- Depth, parameter-count and BN comparisons
- Analytical 3×3 vs. 5×5 parameter comparison
- Receptive-field analysis
- CSV/JSON result export

## Notebook
Open **VGG_CIFAR10_Complete_Research_Notebook.ipynb** in Google Colab and run the cells from top to bottom.

The notebook is designed for a Colab GPU such as a T4. The default experiment budget is 30 epochs per model and can be increased for a stronger final run.

## Reproducibility
A fixed random seed is used for the train/validation split and experiment setup. Exact results can still vary slightly because of GPU and software-version differences.

## Important methodological note
The original VGG paper was developed for large-scale ImageNet recognition. This project uses the VGG convolutional design adapted to CIFAR-10's 32×32 input resolution, rather than copying the original ImageNet classifier unchanged.
